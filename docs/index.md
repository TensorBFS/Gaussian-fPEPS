# Gaussian-fPEPS Documentation

Welcome to the documentation for Gaussian-fPEPS, a Python implementation for studying projected d-wave superconducting states using fermionic Projected Entangled Pair States (fPEPS).

## Overview

This project implements numerical methods for:

- Gaussian fermionic state calculations
- Correlation function computations
- Momentum space analysis with mixed boundary conditions
- Efficient tensor network operations
