# Post Processing of Permutation

Let us start from the origin Majorana Representation in $\Gamma_{\mathrm{in}}$. It is very clear that the order of Majorana fermions is,

$$(f_1,f_2,\ldots,f_{N_f},r_1,l_1,r_2,l_2,\ldots,r_\Lambda,l_\Lambda,d_1,u_1,d_2,u_2,\ldots,d_\Lambda,u_\Lambda).$$

Since we want to translate it to the local Hilbert space and construct corresponding local Hilbert space. Let's write down the order of fermions for local tensor.

$$(u_1,u_2,\ldots,l_1,l_2,\ldots,f_1,f_2,\ldots,d_1,d_2,\ldots,r_1,r_2,\ldots).$$
